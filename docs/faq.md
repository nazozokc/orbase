# FAQ

## データはどこに保存されますか？

`~/.orbase/` に保存されます。詳しくは [データ形式](./data) を参照してください。

## 編集するエディタを変えられますか？

はい。`EDITOR` 環境変数を設定してください。

```bash
export EDITOR=nvim
```

## データは同期されますか？

いいえ。orbase 自体はネットワーク同期を行いません。必要なら `~/.orbase/` を Git、バックアップツール、同期サービスなどで管理してください。

## コマンドが見つかりません

グローバルインストール先が `PATH` に含まれているか確認し、`orbase --version` でインストール状態を確認してください。

## `orbase calendar 2026 9` が9月ではなく10月になります

`month` 引数は 0 始まりです。`0` が1月、`11` が12月に対応します。9月を表示するには `orbase calendar 2026 8` を実行してください。詳しくは [コマンド一覧](./commands#引数) を参照してください。

## `orbase calendar 2026` が1月ではなく今月になります

`month` を省略したときの既定値は1月ではなく現在の日付の月です。1月を表示したい場合は `orbase calendar 2026 0` のように `month` を明示してください。

## カレンダーにタグで絞り込んだタスクだけを表示できません

カレンダーのタスク表は期限（`dueDate`）が指定した年月と一致するタスクを表示します。タグは絞り込み条件になりません。タグで絞り込むには `orbase search tags <タグ>` を使ってください。詳しくは [タグが現れる場所](./tags#タグが現れる場所) を参照してください。

## カレンダーにメモや日記が表示されません

カレンダーは `~/.orbase/task/` のタスクだけを表示します。メモと日記は対象になりません。

## タグの候補に欲しいタグが並びません

タスクで新規作成したタグだけが `~/.orbase/tags.json` に登録され、選択肢になります。メモの front matter に書いたタグや、`tags.json` に無い名前は候補に出ません。`~/.orbase/tags.json` にタグ名を手で追加すると候補に入ります。詳しくは [タグ](./tags) を参照してください。

## `orbase task tagdel` でエラーになります

`orbase task tagdel` は実装途中で、現時点では引数を受け取らず `TypeError: tagString.filter is not a function` で終了します。不要なタグは `~/.orbase/tags.json` を直接編集して削除してください。

## `tags.json` を編集してもタスクのタグが消えません

`tags.json` はタグ名の候補一覧にすぎません。タスクに付与済みのタグは各タスクの JSON の `tag` 配列に保存されています。対象タスクの `tag` 配列、またはメモの front matter の `tags` を併せて編集してください。
