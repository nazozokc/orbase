# FAQ

## データはどこに保存されますか？

`~/.mybase/` に保存されます。詳しくは [データ形式](./data) を参照してください。

## 編集するエディタを変えられますか？

はい。`EDITOR` 環境変数を設定してください。

```bash
export EDITOR=nvim
```

## データは同期されますか？

いいえ。mybase-cli 自体はネットワーク同期を行いません。必要なら `~/.mybase/` を Git、バックアップツール、同期サービスなどで管理してください。

## コマンドが見つかりません

グローバルインストール先が `PATH` に含まれているか確認し、`mybase-cli --version` でインストール状態を確認してください。

## 起動時に `ENOENT ... config.json` と表示されます

`~/.config/mybase/config.json` が未作成のとき、毎回このエラー表示が出ます。処理は既定の保存先（`~/.mybase/`）で続行されるため、そのまま利用できます。表示を消すには `mybase-cli init` で設定ファイルを作成してください。

## `mybase-cli calendar 2026 9` が9月ではなく10月になります

`month` 引数は 0 始まりです。`0` が1月、`11` が12月に対応します。9月を表示するには `mybase-cli calendar 2026 8` を実行してください。詳しくは [コマンド一覧](./commands#引数) を参照してください。

## `mybase-cli calendar 2026` が1月ではなく今月になります

`month` を省略したときの既定値は1月ではなく現在の日付の月です。1月を表示したい場合は `mybase-cli calendar 2026 0` のように `month` を明示してください。

## カレンダーにタグで絞り込んだタスクだけを表示できません

カレンダーのタスク表は期限（`dueDate`）が指定した年月と一致するタスクを表示します。タグは絞り込み条件になりません。タグで絞り込むには `mybase-cli search tags <タグ>` を使ってください。詳しくは [タグが現れる場所](./tags#タグが現れる場所) を参照してください。

## カレンダーにメモや日記が表示されません

カレンダーは `~/.mybase/task/` のタスクだけを表示します。メモと日記は対象になりません。

## `mybase-cli search string` で日記が見つかりません

現在のバージョンでは、日記はキーワード検索の対象になりません。`~/.mybase/diary/YYYY/MM/` の月ディレクトリをファイルとして読もうとしてエラーになるためです。タスクとメモは通常どおり検索されます。日記を探すには `~/.mybase/diary/` 以下を直接開いてください。

## `mybase-cli diary edit` が `No such file or directory` になります

`edit` / `del` は入力した年・月・日を `~/.mybase/diary/YYYY/MM/` 以下へそのまま繋げてパスを作るため、月・日はファイル名と同じゼロ埋め 2 桁（`08`、`01`）で入力します。`8` のように桁が足りないパスは存在しません。

## タグの候補に欲しいタグが並びません

タスクで新規作成したタグだけが `~/.mybase/tags.json` に登録され、選択肢になります。メモの front matter に書いたタグや、`tags.json` に無い名前は候補に出ません。`~/.mybase/tags.json` にタグ名を手で追加すると候補に入ります。詳しくは [タグ](./tags) を参照してください。

## タグを消したいときは

`mybase-cli task tagdel` を実行すると、`~/.mybase/tags.json` に登録されたタグ名がチェックボックスで表示されます。削除したいタグを選んで submit してください。選ばれなかったタグだけが `tags.json` に残ります。詳しくは [タグを削除する](./tags#タグを削除する) を参照してください。

## `mybase-cli note tagdel` でメモのタグが消えません

`note tagdel` が操作するのは `~/.mybase/book.json`（作成した本棚名の一覧）で、メモの front matter の `tags` には触れません。メモのタグを消すには、メモを開いて front matter の `tags` を直接編集してください。

## `tags.json` を編集してもタスクのタグが消えません

`tags.json` はタグ名の候補一覧にすぎません。タスクに付与済みのタグは各タスクの JSON の `tag` 配列に保存されています。対象タスクの `tag` 配列、またはメモの front matter の `tags` を併せて編集してください。
