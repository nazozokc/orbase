# FAQ

## データはどこに保存されますか？

`~/.orbase/` に保存されます。詳しくは [データ形式](./data) を参照してください。

## 編集するエディタを変えられますか？

はい。`EDITOR` 環境変数を設定してください。

```bash
export EDITOR=nvim
```

## データは同期されますか？

いいえ。orbase 自体はネットワーク同期を行いません。必要なら `~/.orbase/` を Git、バックアップツール、同期サービスなどで管理してください。

## コマンドが見つかりません

グローバルインストール先が `PATH` に含まれているか確認し、`orbase --version` でインストール状態を確認してください。
